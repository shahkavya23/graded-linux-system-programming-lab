# Graded Lab Assignment — Linux System Programming (Modules 5–10)

This public repository contains the complete submission for all five questions. Each question has its own folder with source code, commands, explanations, sample inputs, and captured output.

## Repository map

- `Q1_duplicate_submissions/` — duplicate detection, unique backup, report, and error log.
- `Q2_process_monitor/` — `fork()`, `waitpid()`, timeout monitoring, and signal termination.
- `Q3_file_processing/` — POSIX `open`, `read`, `write`, `lseek`, and `close` employee store.
- `Q4_log_monitor/` — `tail`, `grep`, redirection, pipes, and `/dev/null`.
- `Q5_vi_recovery/` — evaluation of vi recovery mechanisms and recommended procedure.

## Linux verification

The C programs require GCC and a POSIX/Linux environment. Run the commands listed in each folder's `COMMANDS.md`. Generated runtime files are kept under each question's `run/` directory and are intentionally included as evidence for grading.

## Academic note

The explanations are written to make the design decisions and observed outputs explicit, as required by the assignment.
